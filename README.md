# r02pro

Source of the [r02pro](https://CRAN.R-project.org/package=r02pro) R package, the companion to the book
[R Programming: Zero to Pro](https://r02pro.github.io/). It ships the datasets used in the book:
`gm`, `gm2004`, `sahp`, and `ahp`.

Install the released version from CRAN:

```r
install.packages("r02pro")
```

Or the development version:

```r
# install.packages("remotes")
remotes::install_github("yangfengstat/r02pro")
```

Book source: https://github.com/r02pro/r02pro_source
